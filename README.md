# IDS ChildShield Climate AI – Backend API

IDS ChildShield Climate AI is an open-source climate-health intelligence platform developed by Inclusive Digital Solutions & Consulting (IDS).

This backend API powers ChildShield’s core platform services, including:

- Climate risk analysis and classification
- AI-powered chatbot communication workflows
- Community alerts via SMS, USSD, and messaging channels
- Campaign management for clinics, NGOs, and public health organizations
- Health-risk scoring and operational analytics

## Technology Stack

- PHP
- Laravel Framework
- REST APIs
- MySQL / PostgreSQL
